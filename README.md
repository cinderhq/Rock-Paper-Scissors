# Rock Paper Scissors

A Rock Paper Scissors game built as a JavaScript practice project.

## About

This project explores the logic behind a simple game, including player choices, computer choices and determining the winner.

## What I Learned

- JavaScript variables and conditionals
- Handling user interactions
- Writing game logic
- Updating results based on different outcomes

## Technologies

- HTML
- CSS
- JavaScript

## Getting Started

1. Open the project folder.
2. Open the main HTML file in your browser, if the project does not require a local server.
3. Play the game and test different outcomes.
